# 证据目录

本资料包的全部证据以机器可读形式保存在两处：

- `../packets/`：三份完整归约成果快照（含 source、outputs、source_digest、digest），
  可经 `slitweb.artifacts.verify_packet` 复核。
- 各 JSON 文件内每条记录的 `evidence_sources` 字段：指认该结论来自哪个归约行
  （如 `exclusion/乙卷/3`、`defect_review/乙卷/亮线`、`shared/亮线`）与哪份成果摘要。

本目录预留用于现场返检后回填纸质/影像证据（保持离线，不写入工作台、不联网）。
