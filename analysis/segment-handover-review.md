# 窄幅交接评议：子卷局部交付的证据边界

## 结论摘要

用现有分切结果，**可以**把「客户只收母卷中的一段」表达清楚，但两种表达的证据强度不同：

- **整幅定尺分段**（子卷全幅 × 纵向区间）：现有 `release / trim / runs / yield_plan / losses / exclusion`
  原生就是这个口径，今天就能签，代价是产量保守。本例可交 `y[0,560] × 40 mm`，
  即子卷的 56%；`trim`、`runs`、`yield_plan` 三处数字互相闭合。
- **限定幅域取料**（子卷横向子区间 × 纵向）：现有结果**只能重建、不能断言**。
  `origin` 是唯一同时带母卷 x 与 y 的输出，可以逐带并集出覆盖；但
  `release / trim / runs / yield_plan / losses` 全是纵向口径，横向安全边距没有字段，
  重大疵点的 3 mm 幅宽也没有复检佐证。本例低带可重建出全长覆盖，
  但声明的 5 mm 横向净距里只有 3 mm 被检验窗认证。

因此：**读法一可直接沿用旧签封单的语义；读法二必须先落一个带版本号的可选阶段，
并满足第 7 节的证据条件，否则不应签发。**

## 1. 评议范围与可复算材料

- 本评议不新增业务功能，不修改 `slitweb/` 的任何计算。
- 例子：`examples/segment-sample.json`（对象 `窄幅交接卷-31`，合成数据）。
- 复算：`python3 -I analysis/recompute_segment.py`。脚本调用未改动的
  `Workbench.analyze`，再用区间并集从现有输出里重算两种读法；所有数字都可在
  输出的 `layout / transfer / coverage / release / trim / trace / exclusion /
  face / defect_review / origin / shared / runs / yield_plan / losses` 中找到来源。
- 脚本同时断言：去掉 `review` 块后，8 个基础阶段与带复核版本逐字段一致，
  即旧报告仍可原样引用。

## 2. 示例与关键几何

母卷 100 mm × 1000 mm，纵向修剪预留 `margin = 10`。`乙卷` 位于母卷 `x[50,90]`，
幅宽 40 mm，**反绕**。

| 事实 | 子卷坐标 | 母卷坐标 | 说明 |
|---|---|---|---|
| 重大疵点 `窄脉` | x[19,22] y[570,600] | x[68,71] y[400,430] | 只占幅宽 3 mm（7.5%） |
| 复检缺口 | y[600,640] | y[360,400] | 整幅口径，无 x 信息 |
| 疵点预留段 | y[560,610] | y[390,440] | 疵点 ±10 mm |
| 预留 ∩ 缺口 | y[600,610]，10 mm | — | 两因在边界上重叠 |
| 局部复检窗 `乙左带缺口窗` | x[0,17] y[560,640] | x[73,90] y[360,440] | 只覆盖左侧带 |

整卷判读（现有结果）：`release=blocked`（1 个重大疵点），`coverage.missing=[[600,640]]`，
`trim=[0,560]`，`losses = {eligible 920, blocked 40, mixed 10, blind 30}`，四类互斥且合计 1000。
`defect_review` 对 `窄脉` 是 `blind`：没有任何检验矩形的 x 范围碰到 `[19,22]`。

## 3. 读法一：整幅定尺分段

### 3.1 允许范围由哪些证据解释

| 证据 | 在例子中的值 | 解释了什么 |
|---|---|---|
| `release` | `blocked, count=1, evidence=[窄脉]` | 整卷为什么不能整卷放行 |
| `coverage.missing` | `[[600,640]]` | 哪一段纵向未复检 |
| `transfer` | `x[19,22] y[570,600] major` | 疵点本体位置，用于算预留段 |
| 输入 `margin` | 10 | 预留段 `y[560,610]` |
| `exclusion` | `1 eligible 560, 2 blocked 40, 3 mixed 10, 4 blind 30, 5 eligible 360` | 允许段与禁保段的分界，逐个可核 |
| `trim` | `[0,560]` | 最长连续可交段 |
| `runs` | `乙卷/1 [0,560]→origin[440,1000]`、`乙卷/5 [640,1000]→origin[0,360]` | 可交段回到母卷的纵向位置 |
| `yield_plan` | 200 mm 定尺出 3 段（610 mm）；560 mm 出 1 段；1000 mm 出 0 段 | 定尺能不能落在单段内 |
| `losses` | `blocked 40 + mixed 10 + blind 30` | 不可交的 80 mm 去往何处 |

可交面积 `560 × 40 = 22400 mm²`，占整卷 56%；不可交 `80 × 40 = 3200 mm²`。
这组数字**不需要任何横向假设**，也不依赖疵点只有 3 mm 宽——整幅口径下，
疵点占多宽都一样阻断整个横截面。

### 3.2 哪些证据解释不了

- `transfer.x0/x1`（3 mm 幅宽）**不参与**允许范围的推导；读法一无法回答
  「绕开这 3 mm 能否多拿产量」。
- `face` 只有窗口并集面积（本例 `38160/40000`），说明不了哪一条带完整。
- `defect_review=blind` 既不能确认也不能否定 3 mm 的边界，但整幅口径不依赖它。
- `shared.kept=3` 说的是「疵点宽度留在子卷里」，不是「留在交付段里」。
- `origin`、`layout.winding` 对整幅口径是冗余信息，读了也不会改变结论。

## 4. 读法二：限定幅域取料

取子卷左侧带 `x[0,14]`，距疵点边 `x=19` 留 5 mm。反绕映射到母卷 `x[76,90]`，
即母卷高 x 侧的边带，现场只需再开一刀。

### 4.1 同一批证据如何重建带级覆盖

`origin` 给出每个检验矩形的母卷 x、y。把与母卷带 `x[76,90]` 相交的矩形取 y 区间并集，
再并上 `coverage.missing` 的补集（整幅复检窗对所有带都有效），得到：

- 低带 `x[0,14]`：`[[0,1000]]`，**盲区 0**，可取 `14 × 1000 = 14000 mm²`；
- 镜像带 `x[27,40] → 母卷 x[50,63]`：盲区仍是 `[[360,400]]`（40 mm），
  净覆盖 `960 mm × 13 mm = 12480 mm²`。

同一条子卷级 `missing=[[600,640]]`，在低带上被 `乙左带缺口窗` 补掉，在镜像带上没有窗，
于是两个带宽相同量级的带，覆盖结论相反。**带级覆盖不是子卷级 `missing` 的按比例缩放。**

两个反事实值得写进交接说明：

- 只看子卷级复检窗（`coverage` 的补集），低带在 `y[360,400]` 仍盲 40 mm；
  是局部窗把这一段补上，局部窗不是装饰。
- 若忽略 `winding=reverse`，把子卷 `x[0,14]` 直接当母卷 x，会落到母卷 `x[50,64]`，
  同样报盲 40 mm。绕向错了，证据会指向另一条带。

横向净距的证据强度要单独说：唯一覆盖缺口段的局部窗止于子卷 `x=17`，
只把带边外 3 mm 认证为 clear；声明的 5 mm 中还有 2 mm（`x[17,19]`）落在窗边与
测得疵点边之间，只有疵点矩形这一条单次测量作依据。也就是说，
**5 mm 是政策参数，不是被复检认证的宽度**；本例可被证据支持的净距上限是 3 mm。

### 4.2 哪些证据解释不了

- `release / trim / runs / yield_plan / losses` **没有横向子区间**：
  本例 `yield_plan` 对 1000 mm 定尺报 0 段，但低带实际上能放 1 段全长；
  这不是算错，是这些阶段看不见带宽。
- `coverage.missing` 是整幅口径：对低带偏保守（带已全覆盖），对镜像带又恰好相同；
  它既不能证明低带已检，也不能单独暴露镜像带的 40 mm 盲区。
- 带级重建默认 `checks` 是**整幅**复检窗（合同里 `checks` 只有 child/start/end，没有 x）。
  这是合同的既定语义，不是从数据里验证出来的结论；若现场复检其实只看了局部幅面，
  低带的「全覆盖」会被高估。
- 没有 `review` 的旧包根本不含带 x 的检验矩形：`origin` 是可选阶段产物，
  基础包只有纵向 `coverage`。因此读法二无法对旧基础包做事后重算。
- `face` 只有总面积，不能定位到带；`face.evidence` 的窗口 id 必须回到 `origin` 才有 x 信息。
- `defect_review=blind`：3 mm 幅宽没有被任何复检窗佐证，疵点是否更宽（毛边、渗色）未量化。
- 合同 `margin` 只定义纵向安全边距；横向 5 mm 没有字段，也不进摘要，改了就不可追溯。
- `trace` 只回母卷 y 区间，不带 x 带，交接员无法用它定位带。
- `scrap` 只记刀间边料，不记「带外侧剩余的子卷宽度」，剩余幅面去向不在账上。

## 5. 证据对照表

| 现有输出 | A 整幅分段 | B 限定幅域 |
|---|---|---|
| `layout`（刀位、绕向） | 只用于确认子卷边界 | **必需**：正/反绕决定子卷 x 与母卷 x 的映射 |
| `transfer.x0/x1` | 不参与 | 决定疵点所在带与横向净距 |
| `transfer.y0/y1` + `margin` | 决定预留段 | 同左 |
| `coverage.missing` | 直接给出禁保纵向段 | 只给整幅口径，需与局部窗重建 |
| `release` | 解释整卷为何阻断 | 只有子卷级，不能签带 |
| `trim` / `runs` / `yield_plan` / `losses` | 原生可用 | 纵向结论可用，横向结论缺失 |
| `exclusion` | 分因长度账，四类互斥 | 可作子卷级上下文，不能切成带 |
| `face` | 面积粗证 | 只能给窗口清单，不能定位带 |
| `defect_review` | 不依赖 | 本应为横向宽度提供佐证；本例为 blind |
| `origin` | 冗余 | **唯一**同时含母卷 x、y 的现有输出 |
| `shared` | 可解释边料分摊 | 只说明「留在子卷里」，不说明「留在交付带上」 |

## 6. 两种交接语义的落地影响

### 6.1 现场测量

- **A 整幅分段**：只测长度（从子卷哪一端量、走卷方向、是否含切口留量），
  横向由刀位和现有切边保证。本例量 `560 mm` 即可，量具和旧流程一致。
- **B 限定幅域**：要测带的两条边，其中一条通常是子卷既有切边，另一条是新开刀；
  还要测带边到疵点边的净距，并确认反绕方向下「子卷 x=0」对应现场哪一侧。
  本例 3 mm 的阈值与常见卷尺/光电边检的重复性同量级，必须写清量具、基准边和
  读数方向；`x[0,14]` 与镜像 `x[27,40]` 在卷面上是两条不同的带，混一条就会
  把有 40 mm 盲区的带当成全覆盖带。

### 6.2 遗漏风险

- **A**：风险方向是**过度拒收**。缺口与预留段按纵向并集扣除，`mixed` 的 10 mm
  只算一次，不会把疵点或盲区漏进交付段；代价是那 80 mm 对 `x[0,14]` 的带其实可交，
  却因整幅口径被一并扣掉，且全长 1000 mm 无法作为一段交付。
- **B**：风险方向是**漏检**，且有三个独立来源：
  1. 带级覆盖必须从检验矩形重建。少一个局部窗、绕向映射错、x 基准偏 1–2 mm，
     都会把盲区算成已检；本例镜像带就是现成的反例。
  2. 重大疵点宽度只有一次测量（`defect_review=blind`），真实边界更宽时净距被吃掉的
     部分没有账。
  3. 带外剩余幅面必须同时处置（改规、降级或判边料）；若只签带、不处置剩余，
     同一段材料可能被读法一和读法二同时承诺。本例两者在 `x[0,14] × y[0,560]`
     上重叠 `7840 mm²`，双签就是重复计量。

### 6.3 旧报告可读性

- **A**：与旧签封单同语义。旧报告里的 `release=blocked`、`trim=[0,560]`、
  `runs`、`yield_plan` 都可以原样引用；新增的只是「按段交付」这一层商务措辞，
  不改任何阶段字段。复算脚本已验证：去掉 `review` 后基础阶段逐字段一致。
- **B**：旧报告**没有横向结论**，不能说「旧报告已经允许这条带」。可行的做法是
  沿用 `review` 可选阶段的前例：新增带版本号的阶段（例如按带 id 给出
  `child / band / x0 / x1 / 母卷映射 / 覆盖 / 净距 / 状态`），基础阶段保持字节不变，
  跨版本比对只报「新增」。若把带结论塞进现有 `release` 或 `trim`，
  旧包与新包会在同一行上变值，历史对照和导出快照都会失去可读性。

## 7. 采用条件

**读法一（整幅分段）值得采用，当：**

1. 现结果是 `release=blocked`，但 `trim`/`runs` 给出至少一个满足定尺的连续段；
2. 客户接受整幅宽度，且不要求用掉疵点另一侧的余量；
3. 缺口是纵向可表达的（现合同天然满足）；
4. 旧报告需要继续可引用。

本例四条全满足：560 mm 全幅 1 段、200 mm 3 段，均可签。

**读法二（限定幅域）值得采用，仅当以下条件同时成立：**

1. **带级覆盖闭合**：整幅复检窗的补集，加上与该带相交的局部 `origin` 矩形，
   并集覆盖带的全部交付长度。本例低带满足，镜像带不满足（40 mm 盲区）。
2. **横向净距有检验证据**：带边到每个重大疵点边的距离 ≥ 声明政策值，且这段距离
   本身被检验窗覆盖，而不只是被疵点矩形声明。本例声明 5 mm、认证 3 mm，
   因此要么把政策降到 ≤3 mm，要么补一个达到子卷 `x≥19` 的局部窗。
3. **疵点宽度可佐证**：`defect_review` 不为 `blind`，或对宽度声明保守余量并记录。
   本例不满足。
4. **绕向与映射显式**：记录 `winding`、子卷带 → 母卷带的换算、现场基准边；
   反绕时尤其不能把子卷 x 直接当母卷 x。
5. **剩余幅面已处置**：带外宽度有明确去向，避免与读法一重复计量。
6. **旧包不变**：带结论进入新的可选阶段并带版本号；基础阶段逐字段保持，
   跨版本比对只出现「新增」行。

## 8. 建议与不做什么

- 建议：先把**读法一**作为交接语义落地，因为它完全由现有输出支撑，
  且不改变旧报告口径；同时把读法二所需的 `origin` 证据、横向政策和带 id
  作为下一版可选阶段的输入条件沉淀下来。
- 本例若客户坚持要「绕开 3 mm 拿全长」，应先补两项证据：一条覆盖
  `x[17,19]`（或更宽）的局部窗，以及对 `窄脉` 的宽度复核；在此之前，
  低带的全长结论只能算「可重建的观察」，不是可签的判定。
- 不做：本次不新增带级 `release`、不改 `coverage` 的整幅口径、不把横向边距塞进
  现有 `margin` 字段，也不改写任何历史包。评议与例子只用于支撑决策。

## 9. 复算方法

```sh
python3 -I analysis/recompute_segment.py
```

脚本会打印包摘要、两种读法的全部数字、反事实与「现有输出不承载」的清单，
并在末尾声明两件事：数值可由现有输出重算；去掉 `review` 后基础阶段不变。
换输入时先改脚本里的 `CHILD / DEFECT / LATERAL_MARGIN` 与断言常量，
再按打印结果逐项核对。示例为合成数据，3 mm / 5 mm 只用于说明证据边界，
不代表真实工艺公差。
