# 绕向翻转回归证据

## 目标

同一块实物材料从正绕（forward）改成反绕（reverse）时，验证三件事：

1. **母卷回查（trace）与复检反查（origin）仍指向同一个疵点**——两版输出都还原到
   同一母卷实物矩形，证据集合逐元素一致；
2. **走卷标签确实换了位置**——`layout.state` 从 forward 变成 reverse，
   转印疵点的子卷坐标在两个轴上都发生镜像，刀位几何不动；
3. **实物不变量保持一致**——面积、疵点归属、封样判定、分因长度等不随绕向漂移。

## 运行

```sh
python3 tests/run_regression.py
```

在临时 SQLite 成果库与临时回环端口上跑 17 个测试，覆盖从 HTTP 输入
（evaluate → seal → compare → export 下载）到封存快照的完整链路。
不依赖任何第三方包，Python 3.11 标准库即可。

## 夹具几何（tests/winding_fixture.py）

母卷 120 mm × 1000 mm，三个刀位、四条边料带：

| 对象 | 母卷幅向区间 | 说明 |
|---|---|---|
| 甲卷 | 30..56 | |
| edge-2 | 56..68 | 中间废料带 |
| 乙卷 | 68..100 | |
| edge-3 | 100..108 | 废料带 |
| 丙卷 | 108..118 | 无疵点、无复检，覆盖全盲 pending 路径 |
| edge-1 / edge-4 | 0..30 / 118..120 | 两端边料 |

疵点设计刻意不对称，使「只翻一个轴」无法与另一版对齐：

| 疵点 | 母卷矩形 | 作用 |
|---|---|---|
| 跨刀疵 | 50..70 × 200..270 | 横跨 edge-2，在甲卷内 6mm、乙卷内 2mm，走卷长 70mm；非对称跨刀位 |
| 甲内疵 | 34..40 × 400..418 | 6×18 非对称 |
| 乙内疵 | 90..98 × 520..545 | 8×25；与回查窗在 y=520 两维贴边 |
| 贴边疵 | 64..68 × 800..812 | 恰在 68 处贴乙卷左边沿，左闭右开下不相交 |

两块**恰贴边不相交**的区域：

- 回查实物窗（乙卷，y 240..520）与乙内疵仅在 y=520 边界相接，幅向投影完全落入
  其幅向区间——严格 `<` 判交为空，`<=` 会把乙内疵误计入回查证据；
- 复检「贴边窗」（母卷 68..70 × 270..330）与跨刀疵仅在 y=270 相接，
  幅向投影落入跨刀疵在乙卷的片段——`<=` 会误判命中。

## 允许变化的字段 vs 实物不变量

### 允许随绕向变化（compare 差异行白名单 ALLOWED_CHANGES）

| 阶段 | 允许变化的字段 |
|---|---|
| layout | state（forward/reverse 标签） |
| transfer | x0, x1, y0, y1（子卷坐标） |
| coverage / release | missing（缺口的子卷坐标表达） |
| trim | start, end, missing |
| exclusion | id, start, end, length, state, evidence（按序号对齐，实物分段重排） |
| runs | id, start, end, length, state, evidence, origin（序号对应不同实物段） |
| yield_plan / losses | evidence（段编号引用变化） |

### 实物不变量（INVARIANT_STAGES，compare 必须零差异）

`scrap`、`trace`、`face`、`defect_review`、`origin`、`shared` 六个阶段
两版逐行完全相同。此外测试独立重算并断言：

- 每条转印疵点的**面积与幅向/走卷跨度**两版相等；
- 转印矩形**独立还原回母卷**后，与原疵点在该刀位内的实物片段逐边重合；
- `runs.origin` 母卷纵向区间的**集合**两版相同；
- 封样 `state/count/evidence`、`losses` 各状态长度、`yield_plan` 定尺容纳数相同；
- 修剪段映射回母卷后是同一实物区间。

测试侧的镜像换算（`tests/invariants.py`）独立实现，不 import 被测领域代码，
避免与实现共用同一处错误。

## 断言强度：变异矩阵

对生产代码做受控变异，确认套件真的会红（数字为失败测试数）：

| 变异 | 位置 | 结果 |
|---|---|---|
| M1 反绕只翻纵轴（漏翻横轴） | geometry.map_defect | 6 个失败 |
| M2 反绕只翻横轴（漏翻纵轴） | geometry.map_defect | 8 个失败 |
| M3a 复检贴边算交集（`<`→`<=`） | geometry.overlap | 2 个失败 |
| M3b 回查贴边算交集（`<`→`<=`） | rules.decide | 3 个失败 |
| M3d 转印门限贴边算交集（`>=`→`>`） | geometry.map_defect | 4 个失败 |

### 为什么没有「边料带贴边算交集」变异

`intervals.gaps()` 产出的边料带之间必然隔着刀位，任意两条边料带不共享端点，
因此 `domain.evaluate` 里边料判交的 `<` 放宽成 `<=`，对任何只落在单条边料带内
的疵点都产生相同结果——该变异在当前数据合同下**不可观察**，无法构造有效输入。
疵点与刀位贴边的路径走的是 `map_defect` 的 `x0 >= x1` 门限，由 M3d 覆盖。
强行断言一个不可证伪的场景只会制造假信号，故不纳入。

### 为什么不只比总面积

`test_total_area_alone_is_not_enough` 演示：把一条转印矩形整体平移 6mm，
它自身的面积与跨度完全不变，总面积断言会放行；但逐字段坐标与母卷还原断言
立即失败。非对称形状 + 母卷还原比对让「面积对但位置错」无处可藏。
